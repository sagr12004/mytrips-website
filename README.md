## 📌 About the Project
**MyTrips** is a beginner-friendly **travel planner web application** built for learning and practice.  
It helps users **explore destinations**, **search & filter cities**, and **plan trips** by selecting dates, budget, and number of travelers.

Users can also **save trips** securely using authentication.

## ✨ Features
✅ Browse popular cities worldwide with images  
✅ Filter destinations by country  
✅ Search cities instantly (dynamic search)  
✅ View destination details  
✅ Plan trips with:
- 📅 Start Date & End Date  
- 💰 Budget  
- 👥 Number of Travelers  

✅ Save planned trips (for logged-in users)  
✅ Responsive design (mobile + desktop)  
✅ User Authentication using Supabase:
- Sign Up  
- Login  
- Logout  

---

## 🛠️ Technologies Used
- **HTML5** — Page structure  
- **CSS3** — Styling & responsive layout  
- **JavaScript (ES6)** — Functionality, DOM handling  
- **Supabase** — Database + Authentication  
- **Unsplash API** — Destination images
